恢复只证明当前权威及事实，不授予写、测试、Review、Git、浏览器/设备或外部权限。先从明确项目根及其AGENTS进入固定BOOTSTRAP，校验真实路径和拓扑；普通非Git项目不以Git决定项目根。可选GIT_WORKTREE沿原任务descriptor验证唯一controlRoot与executionRoot，旧复制控制材料不能替代原权威；Maintenance仍按自己的CONTROL/TARGET拓扑解析。

读取当前project、Controller、有效纠正、policy及必要采用完成事实，从项目pin及.ai-workspace/upgrade-recovery/<version>/state.json的distributionBinding定位唯一固定运行来源，按实际REGISTER/UPGRADE/REFRESH完成链核对并读取TOOLCHAIN。开发HEAD、网络、其他项目或任意新包不作fallback。首次/新来源须完整资格验证；普通已采用来源核真实当前完成链、独立固定绑定、manifest原始身份与声明，以及实际消费的实现/catalog/规则和必要依赖，不递归扫描未消费测试、历史或其他包成员，也不以轻量事实声称全包健康。完整采用、资格和分发验证仍完整核包，不把声明合成为完整Facts或新Proof；不加跨请求缓存。弱绑定、仅标记true或实际漂移均不足，未完成采用先恢复原事务。

已有taskId直接读取原卡及必要项目事实，未知任务才用索引定位；STATUS按全局事实需要读取。新请求先按稳定成果subject、项目卡/质量策略及当前人类决定选择真实上下文：需卡用TASK，允许省卡但有成果门或有限写入/多步成果用PROJECT_WORK，无适用任务的只读用PROJECT_READ_ONLY，只有无需卡或成果门且许可覆盖的普通工具用PROJECT_EXTERNAL。绑定原请求、成果Owner、实际actor/role/phase、profile、动作/结果、精确范围/保护和适用质量，不把当前操作workType替代发起成果workType。DISCOVER前依TOOL_CONTRACT形成真实IntentEnvelope，取得当前完整必要正文；加载不执行动作或产生许可。缺省LEGACY和旧输入沿原兼容条件，未知不降门。

新事实只重建受影响来源、决定或正文；压缩/换主体/正文不确定须完整恢复当前必需正文，健康调用不逐步FULL_COLD。LOAD_PLAN_RESOLVE只服务支持材料、Framework维护说明、原兼容或无法证明映射时的有界模块回退，不筛catalog或绕保护。实际Git再核对应仓库。普通观察不取项目/source协调锁，不自动重放publication journal；真实事务写者竞争的BUSY保持holder=UNKNOWN，收起本次尝试。显式相关journal的IN_PROGRESS沿原恢复入口；不删同步对象、改pin或补载开发模块。报告真实下一动作及证据上限。

<!-- AIW-REQUIREMENT:PR_PROCESS_REQUIREMENTS_PROGRESSIVE_BOUNDARIES:BEGIN -->
DISCOVER核对完整有效声明、当前权威及真实意图，选择并读取命中规则的完整条件、有序依赖和正文，返回当前义务。采用/变更仍核完整目标集合；未命中正文不作健康证明。每个受治理动作分别满足当前checker/ADMIT，正式结果按真实消费者FINALIZE；已证明等价的checker由ADMIT内完整调用满足。项目预授权范围内的普通工具直接调用并保原返回，不逐工具重建过程链。合法只读查证可作有界NONE批次，不编造任务或逐文件准入。

首次项目工作、压缩、换主体、正文不确定、真实活动切换或适用来源/要求变化时，按当前意图FULL取得全部必要正文。实现中的读取、代码及配套记录可属同一活动；实际TEST_RUN、自查、审核或验证转返修按真实新活动完整加载。保留失败、撤权、保护和未完采用的拒绝；FULL不使这些条件通过。

同一健康活动中，普通文件、包或本地配套操作变化只重核当前权限、范围、真实路线及适用要求。新当前操作由原选择器重算完整O；所需正文B仍全部在实际已读完整集合中，且来源、活动和路线未变时，用原ruleReadRef重绑操作，不调用正文assembler或renderer。新增必要正文、来源/活动/路线变化或正文不确定返回RULE_LOAD_REQUIRED并FULL。O中退出的义务不删除已读正文；规则再次适用不等于新增正文。保存当前完整义务供原FINALIZE消费，历史动作沿原冻结义务，不用今日policy重算旧成功。格式与旧actionRebind分支取TOOL_CONTRACT。

模型只读取一份官方text：模式、真实限制、短来源、有序引用、当前义务及同次去重后的全部必要正文。调用前分别给外层编排和内层命令留足完整输出预算。实际宿主截断时从同次结果补读真实缺失的完整单元及义务；不重新选择、不主动分页、不用摘要、hash或旧收据替代未读正文。不得预载未来活动、按上下文差集裁正文或声称机器PASS证明模型记忆/attention。旧REUSE仅按FULL兼容，不读取previousCoverageRef。

宿主编码/输出需要时，同次DISCOVER用DisplayPath保留官方UTF-8 text；AsJson机器载体由程序捕获，经原官方renderer取text，不直接打印机器JSON。补文只读同一结果；副本和过程材料留至各自最后消费者完成后沿TOOL_CONTRACT释放。固定运行包保持原字节，当前开发来源不能替代它。

仅实际NONE、无包无副作用、向当前USER作普通PLAN/USER_RESPONSE，且无正式Review/接受、TASK_MESSAGE、关闭/责任转换或continuation消费者时，可省独立机械FINALIZE；完整规则读取、事实/限制和未完责任仍履行，不生成后继执行许可。真实跨任务交付、质量动作和责任转换按各自原门；项目预授权直接工具保真实返回并自然交付。

<!-- AIW-REQUIREMENT:PR_RECOVERY_ROLE_REBIND:BEGIN -->
恢复分别绑定任务Owner、Work route actor、临时action grantee/Reviewer和资源安排。健康同任务的role/action rebind可沿NONE/WARM及当前新包继续，单独包失效不自动要求FULL_COLD或Controller签发；旧格式actor缺失保持只读并按MIGRATION_MATRIX完成声明的迁移。

真实Owner/Work route/profile或Controller组合转换按TOOL_CONTRACT的schema1 CONTROL_TRANSITION恢复；发现原controller/task的transitionRef先处理原责任事务，旧主体仅有原计划恢复资格，完成证明持久后再清标记。普通当前卡归档不建立locator或事务：archive完整已保存而active仍为原像可续；active已删且archive完整时，原FINALIZE核窄后像并让所有任务消费者读取实际archive，原逻辑身份不变。缺失、不完整或第三方状态拒绝，不以fresh授权追认，也不全局阻断无关任务。

<!-- AIW-REQUIREMENT:PR_FRAMEWORK_BACKEND_SELECTION:BEGIN -->
backend是项目Framework使用配置，不是任务或动作授权。首次调用或相关来源变化时，以project配置精确匹配TOOLCHAIN的语言无关operation及sealed entrypoint，满足声明runtime/platform；健康绑定可复用。当前只提供powershell7，只有实际发行提供第二个official backend才可沿项目采用切换。

backend变更使受影响配置/包绑定失效，须安全采用边界及fresh recovery。未知backend、缺入口、不支持平台或runtime不可用均停止受影响调用，不从shell猜测，不自动fallback、安装、生成adapter、另造launcher或让用户逐任务选后端。操作格式唯一取TOOL_CONTRACT，真实入口/支持事实唯一取TOOLCHAIN。
