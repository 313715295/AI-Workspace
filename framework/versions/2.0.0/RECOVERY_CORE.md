已知taskId直接读该卡及必要项目事实，未知才读索引定位；STATUS按全局事实实际需要读取。绑定当前请求、Owner、真实actor/role/phase、profile、动作/结果、精确范围/保护、能力和适用Review要求；无适用任务的只读问题用PROJECT_READ_ONLY；项目已明确预授权的普通外部工具请求用PROJECT_EXTERNAL加载真实EXTERNAL意图，不改称NONE或编造任务。两者都只取得规则，不执行工具或产生动作准入。DISCOVER前由当前模型按TOOL_CONTRACT唯一IntentEnvelope段形成真实意图，再按PR_PROCESS_REQUIREMENTS_PROGRESSIVE_BOUNDARIES加载正文。

<!-- AIW-REQUIREMENT:PR_PROCESS_REQUIREMENTS_PROGRESSIVE_BOUNDARIES:BEGIN -->
DISCOVER验证必要全局三源声明与当前权威，按同一真实Intent选择，再验证命中规则的完整公共条件、依赖和正文，返回当前义务及所需全文，不授权。未命中的独立外部正文不读取，不证明其健康；真实采用/变更边界仍验证完整目标集合。按次受治理动作各自checker/ADMIT，正式输出按真实结果和消费者FINALIZE；PROJECT_PREAUTHORIZED覆盖内普通外部工具调用沿当前项目许可直接执行并保原工具返回，不逐次重建D/A/F。没有适用任务的合法只读解释、查证和方案可组成一个有界NONE批次，不逐文件ADMIT或编造任务；转为真实副作用、正式审核或新边界时按实际模式重新判断；项目预授权直接调用不重复动作包链，其他动作仍独立准入。

分开处理来源组合、当前动作决定及正文可用性：来源/规范单元及有序依赖的变化重绑相应内容，权限、任务路线、阶段、决定或执行目标变化重验当前动作；fresh包、工具调用、正常进展和已授权后像本身不要求全部重读。scoped来源身份只证明当前完整选择闭包；授权/不可变对象及实际消费成员仍按各自完整字节严格核对。

首次、压缩、换主体或正文不确定请求FULL，按当前意图选择完整条件与依赖，同次去重后组装全部当前必需正文。工作活动与权限操作分别判断：实现中的读取、源码/测试代码修改和记录可属于同一活动；进入实际TEST_RUN、自查、审核或由验证转返修是活动切换，须完整加载。新增适用要求、真实任务路线或来源实变同样FULL。退出coverage差集执行和未来正文预载；旧REUSE仅兼容为FULL，不打开previousCoverageRef，不返回REUSED零正文或DELTA局部正文。coverage仅为本次来源索引，不证明模型记忆或attention，不要求宿主提供不存在的“当前模型持有全文证明”。真实来源拒绝、撤权、保护或未完采用不能以FULL变成PASS。

同一健康工作活动中的普通文件、包或本地配套操作变化，先经原checker/ADMIT核当前权限、范围、真实任务路线、来源及同一选择器的适用结果。当前规则仍在已完整加载集合内且未新增要求时，可只重绑当前操作，不调用正文装配或显示；已退出的操作专属规则不带入新操作义务，因范围/分类改变而退出的规则不能冒充操作退场。保存的新compact以当前完整selectedObligations绑定raw、view、identity及原FINALIZE；历史消费者读取原冻结义务，不以今日policy重算旧成功。不能先装配全文再以零输出声称复用。新增/重新进入适用规则、必要来源变化或正文不确定时返回RULE_LOAD_REQUIRED，重新DISCOVER取得当前全部正文。该边界不扩旧包权限、不承接未来动作，也不新增缓存、台账或模型记忆证明；精确支持范围取TOOL_CONTRACT。

模型视图以单一text输出模式、真实兼容说明与限制、短来源、每规则有序短引用和当前义务；同次必要完整正文只显示一次，不裁剪条件、依赖或重叠正文。机器来源索引留程序侧。调用前为外层编排和内层命令按完整正文分别留足预算，提升内层不改变外层；只暴露一份官方text，不混入机器JSON或其他长输出。默认一次完整输出；实际宿主截断时从同一结果补读真实缺失的完整单元及义务，不主动分页、不建页票据、不重跑选择。失败和未知保留，不能变成空规则成功。summary、hash、旧receipt或机械PASS不能替代实际缺失正文。

实际宿主跨进程编码/输出限制需要时，按TOOL_CONTRACT在同次DISCOVER显式保留官方UTF-8 text副本（DisplayPath）；机器AsJson由程序捕获，不打印给模型。补文只消费同一结果/官方副本，不重跑解析或重扫项目源文件；默认不保存、不分页，最后消费者完成按原runtime生命周期释放。旧固定版本使用同次AsJson结果及原官方renderer，不热改运行包。

输入、compact、continuation及正式证据的存放/清理取TOOL_CONTRACT；最后消费者未完成前保留其原引用。这里不新增缓存台账、意图服务或模型请求步骤。结构通过不证明语义正确或实际宿主执行。
仅本次实际NONE、无包无副作用，向当前USER作普通PLAN/USER_RESPONSE，且无正式Review/接受、TASK_MESSAGE、关闭/责任转换或continuation消费者时，可省独立机械FINALIZE。当前必要完整规则仍实际读取，事实/来源/限制/未知仍如实说明；不产生假PASS或可被后继借用的成功收据。任一条件不符仍走原收口；PROJECT_PREAUTHORIZED直接工具调用按AUTHORIZATION_MODEL保原返回并自然交付，不伪造机械收据。真实TASK_MESSAGE、正式Review/接受或责任转换仍满足各自门；显式FINALIZE公共入口保持严格。

质量策略启用不改变固定运行来源或恢复权威；当前与原成功历史分别按TOOL_CONTRACT核绑定，不能用今日policy重算旧接受，也不因C而给只读问题造卡。

backend是项目Framework使用配置，不是任务或动作授权。首次调用或相关来源变化时，以project配置精确匹配TOOLCHAIN的语言无关operation及sealed entrypoint，满足声明runtime/platform；健康绑定可复用。当前只提供powershell7，只有实际发行提供第二个official backend才可沿项目采用切换。

backend变更使受影响配置/包绑定失效，须安全采用边界及fresh recovery。未知backend、缺入口、不支持平台或runtime不可用均停止受影响调用，不从shell猜测，不自动fallback、安装、生成adapter、另造launcher或让用户逐任务选后端。操作格式唯一取TOOL_CONTRACT，真实入口/支持事实唯一取TOOLCHAIN。
