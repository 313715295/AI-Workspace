# 软件实现与资源

适用于项目已采用本标准的软件代码和执行逻辑变更；生产者据此实现，审核者据此检查同一成果。

- 改动落在负责该语义的模块，复用已经确认适用的依赖。保持直接调用者、返回值、错误处理和文档中的公开约定一致；私有算法选择不制造第二份业务规则。
- 边界输入在进入状态改变前完成必要校验。校验失败、部分写入、异常和取消不能留下被误认为成功的状态；资源取得和释放覆盖实际失败出口。
- 数据迁移及持久化修改保护已存在的有效数据，拒绝无法解释的混合状态。需要重试时说明幂等或去重条件；未知执行结果不自动重放不可重复动作。
- 性能判断以真实热路径、输入规模和资源约束为依据。检查复杂度、分配、缓存失效、磁盘/网络调用和资源回收中的受影响项；先有可复现依据再引入优化复杂度。
- 依赖实际平台或运行环境的实现显式声明边界。平台差异、序列化、排序、编码和时间处理影响结果时，用受支持环境验证，不从单一环境推断所有平台。
- 交付解释实际行为变化、理由及限制。生成产物和其源文件按项目已有构建关系保持一致，不把仅修改源文件或仅通过局部检查写成完整集成成功。
