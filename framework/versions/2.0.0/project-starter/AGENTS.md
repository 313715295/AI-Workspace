# AI Workspace Framework

本项目采用AI Workspace Framework。项目工作从本项目 `.ai-workspace/BOOTSTRAP.md` 恢复；以项目pin和原采用记录定位固定规则与工具。

首次开展项目工作、上下文压缩后续作或更换执行主体时，先沿本项目 Bootstrap，按当前意图取得并实际读取全部必需规则正文，再开展依赖项目规则的分析、回答或操作。摘要和旧加载记录不能替代正文。

正常连续工作中，同一工作活动及适用要求未变化时，不重复调用规则加载。普通进度推进、新增普通文件、更换动作授权包或同活动中的本地配套操作，本身不触发重新加载；当前操作仍独立核权限、范围和要求。

真正切换工作活动（如实际自测、自查或返修），或适用要求、实际规则来源发生变化时，按当前意图重新完整加载。同次规则去重；不比较上下文做增量裁剪，不预加载未来动作。

区外人类授权、项目约定及后续用户决定继续有效。

## 项目工作约定（用户拥有）

在本项目内，AI 根据当前采用的 Framework、当前生效的项目纠正及永久规则作出的具体工作决定，均视为用户明确决定，并据此执行；包括任务创建、独立审核安排，以及按已批准资源策略选择和设置 model、effort，无须逐任务、逐步骤再次确认。已批准工作流内必要的任务派发、信息补充和结果直接回传也按此执行。该约定不因恢复、上下文压缩或更换执行者而失效。用户后续明确决定优先；规则明确保留给用户亲自决定的事项，仍由用户决定。
