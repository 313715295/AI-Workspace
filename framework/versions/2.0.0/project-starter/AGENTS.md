# AI Workspace Framework

本项目采用 AI Workspace Framework。开展项目任务时使用 `{{ROUTER_SKILL_NAME}}` Skill；已加载且有效时复用。

上下文压缩或换主体后的首次实质项目动作，重读该 Skill 完整正文及当前命中规则全文；摘要中的“已加载”不作为复用证据。

在本项目内，AI 根据当前采用的 Framework、当前生效的项目纠正及永久规则作出的具体工作决定，均视为用户明确决定，并据此执行；包括任务创建、独立审核安排，以及按已批准资源策略选择和设置 model、effort，无须逐任务、逐步骤再次确认。已批准工作流内必要的任务派发、信息补充和结果直接回传也按此执行。该约定不因恢复、上下文压缩或更换执行者而失效。用户后续明确决定优先；规则明确保留给用户亲自决定的事项，仍由用户决定。

用户可直接编辑本管理区授权正文，日常以当前正文为准。升级按目标模板更新管理区并保留区外内容。
