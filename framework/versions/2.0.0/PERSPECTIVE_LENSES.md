# 可选评审视角

REFERENCE_ONLY / NON_AUTHORITY。需要帮助寻找遗漏时，可从下列角度选择能改变当前判断的问题；不规定数量、固定输出格式或视角回执，不替代真实独立Review。

- 用户成果：目标、实际增量和验收是否一致。
- 责任与权限：原始决定、负责人、消费者和操作边界是否清楚。
- 事实与恢复：当前事实、未解义务、中断和交接能否接续。
- 证据与限制：实际观察是否支持结论，失败、未知和反例是否保留。
- 比例与成本：新增机制是否解决真实缺口，现有方案能否充分满足，执行/协调/验证/返工总成本如何。

围绕实际对象和证据形成判断，不模拟专家人格；相同根因的finding合并要求取REVIEW_AND_EVIDENCE。软件专业要求由项目按standards/README显式采用，其他方法按真实需要选择。本文件可直接作为参考阅读，不自动进入原生规则选择或项目policy。
