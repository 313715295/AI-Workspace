# Framework 1.15.0 change log

Baseline: immutable Framework 1.14.1. Release class: `MINOR`.

## Added

- exact requirement-block markers across every runtime normative module and a schema2 fragment contract that binds each native requirement ID to exactly one Markdown block;
- metadata-only `PROCESS_REQUIREMENTS.json` catalog generation and runtime extraction of only selected complete native blocks;
- `NORMATIVE_SURFACE_INVENTORY.json`, which classifies every release file once as runtime normative, action-required, schema/mechanical or explanation/history;
- canonical host-global `ai-workspace-router` Skill plus a root projection and sealed compatibility declaration in `TOOLCHAIN.json`;
- schema3 `ACTOR_BOUND_PROJECT_UPGRADE` authorization with closed bundle/action/profile semantics and exact final-object postimage binding;
- target-version preparation and formal recovery directories for resumable 1.15 adoption, with the active task projected last.

## Changed

- normal recovery now performs minimum-fact binding, full-catalog `DISCOVER`, exact selected-block loading, `ADMIT_ACTION`, action and `FINALIZE_OUTPUT`;
- `LOAD_PLAN_RESOLVE` is support/fallback rather than a normal pre-DISCOVER filter;
- new projects receive only the managed `AGENTS.md` navigation block; Framework no longer copies the router Skill into project repositories;
- 1.14.0/1.14.1 project adoption removes only the exact sealed repo-local router Skill and preserves unrelated project content;
- release work is proportional to actual impact and avoids an unconditional duplicate semantic Review after sealing.

## Preserved

- the complete authorization, correction, project-policy, Review, Git/external and protected-path authority boundaries;
- schema1/schema2 authorization behavior and immutable 1.14.1 bytes;
- project-owned pins, facts and current correction records;
- PowerShell 7 on Windows as the only official/evidenced backend for this release.

## Not added

No second resolver/composer/authority, global registry, service, ledger, poller, background cache, per-tool reload, automatic project conversion, consumer auto-upgrade, new backend or cross-platform CI claim.
