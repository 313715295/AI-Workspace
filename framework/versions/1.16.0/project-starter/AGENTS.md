# AI Workspace Framework

本项目采用 AI Workspace Framework，使用已接入的 `ai-workspace-router` Skill 按需开展治理工作。

在本项目内，AI 根据当前采用的 Framework、当前生效的项目纠正及永久规则作出的具体工作决定，均视为用户明确决定，并据此执行，无须逐任务、逐步骤再次确认。该约定不因恢复、上下文压缩或更换执行者而失效。用户后续明确决定优先；规则明确保留给用户亲自决定的事项，仍由用户决定。

用户可直接编辑本管理区授权正文，日常以当前正文为准。升级按目标模板更新管理区并保留区外内容。
