# Framework 1.16.0 change log

Baseline: immutable Framework 1.15.1. Release class: `MINOR`.

## Added

- one fixed `ADOPTION_PROFILE.json` that declares registration eligibility, direct sources `1.14.1 / 1.15.0 / 1.15.1`, schema4 project control, PowerShell 7, host-global Router navigation, task-last writes, exact enabled-capability binding and process-pack budgets;
- a DISCOVER result envelope with selected complete canonical rule blocks plus a compact reusable receipt containing source/context identities and obligations without `fullText`;
- explicit safe cleanup for exact temporary `aiw-*.json` resolver inputs after both successful and failed runs;
- a narrow schema2 `CONTROL_WRITE` active-task preimage-to-postimage finalization path that preserves task ID/Owner and rejects every other source drift;
- profile-driven root registration and upgrade integration, including exact ordinal-sorted enabled capability IDs passed unchanged into current-pin process composition;
- future-first roadmap presentation and candidate-aware root guidance.

## Changed

- ordinary selected packs use a 32768-byte ceiling, the general absolute ceiling is 65536 bytes, and only verified effective schema1 corrections under clear/no-custom/no-mismatch conditions may use an explicitly marked 98304-byte compatibility ceiling;
- runtime boundaries reuse compact receipts while context is bound and require a new full DISCOVER on uncertainty or source/selection drift;
- version-independent release governance is root-owned, absent from the sealed version payload and excluded from the runtime fragment/catalog surface;
- direct adoption is projected from the profile rather than repeated literal target-version branches in root tools.

## Preserved

- immutable Framework 1.14.1, 1.15.0 and 1.15.1 payloads;
- one composer, canonical Markdown rule bodies, actor-bound authorization, task-last recovery, project-owned corrections/policy, independent Review, separate `OWNER_ACCEPT`, Git/external gates and protected-path boundaries;
- PowerShell 7 on Windows as the only official/evidenced backend for this release.

## Not added

No second schema, resolver, service, registry, ledger, cache, poller, automatic consumer discovery/adoption, automatic host Skill installation, new backend or broader platform claim.
