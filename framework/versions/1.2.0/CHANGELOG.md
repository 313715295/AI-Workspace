# v1.2.0 变更说明

相对 v1.1.0：

- 组织模型改为“一个主控、三个基础专业分管、按需启用专项分管与执行会话”。
- 新增可选的“平台/发行工程分管”，负责平台工具链、SDK/runtime、构建产物、平台适配集成、账号/AppID/设备/测试版本流程和发行准备。
- 明确产品平台和引擎路线仍由主控组织决策；跨域公共契约由对应专业分管共同审核，平台分管不得越权裁决。
- 把下载、安装、许可协议、登录/绑定、AppID、设备授权、上传测试包、提审和正式发布拆成独立授权状态，前一步不自动授权后一步。
- 新增外部工具、账号与发行状态的证据要求：官方来源、精确版本、字节数、哈希/签名、目录与缓存、秘密信息边界、可回收 PoC、产物可复现性和失败恢复。
- `REVIEW_CHECKLIST.md` 新增平台/发行九项验证；`PERSPECTIVE_LENSES.md` 新增平台与发行生命周期视角；任务模板新增 `platform-release` 领域和外部动作授权字段。

兼容性：项目必须显式更新 `project.json.frameworkVersion` 才启用本版本；v1.0.0 与 v1.1.0 保持不变。未涉及正式平台或发行链的项目不需要启动平台/发行分管。
