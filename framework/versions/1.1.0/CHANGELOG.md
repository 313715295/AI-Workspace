# v1.1.0 变更说明

相对 v1.0.0：

- 新增 `WORKFLOW_PLAYBOOK.md`，恢复并修正旧 memory 中详细的改前准备、理论建构、安全网、影响分析、问题路由、关系图、交接和 Git 收口流程。
- 扩展 `REVIEW_CHECKLIST.md`：场景 A/B、风险四维、十二项方案审核、文档八维/四层、代码六层、证伪检查点、行为声明和审核失败学习。
- 新增 `PERSPECTIVE_LENSES.md`，把固定专家人格改造成按风险选择、证据驱动的十二个评审视角。
- 明确审核清单由分管、独立审核和主控阶段门共同使用；执行者只用于自检。
- 修正“发现全部问题就无限扩张”“所有修改都等用户逐项批准”“不确定只问专家不问用户”等过度绝对规则。
- 新任务模板增加风险四维、审核场景、关系图、评审视角、行为声明、额外问题路由和 Git 记录。

兼容性：项目必须显式更新 `project.json.frameworkVersion` 才启用本版本；v1.0.0 保持不变。
