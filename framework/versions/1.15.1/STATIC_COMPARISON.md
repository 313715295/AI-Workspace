| Concern | 1.15.0 | 1.15.1 candidate |
|---|---|---|
| current-pin selected pack | resolver rejects every selection above 12288 bytes | only exact 1.14.x adoption budget failure may be independently recomposed and admitted under the 65536-byte target ceiling |
| bridge authority | actor-bound schema3 package and categorical gates | unchanged; the bridge is read-only compatibility evidence and grants nothing |
| selected rule bodies | complete selected Markdown blocks | unchanged and required in the recomposed bridge pack |
| Router context fixture | repeats a frozen 4452-byte value in each normal context | derives canonical Skill bytes while retaining independent identity, semantic and maximum-ceiling checks |
| task-last recovery | deterministic preparation/recovery and zero writes after task | unchanged |
| stable payloads | immutable 1.14.1 and 1.15.0 releases | unchanged; 1.15.1 is a new candidate directory |
| added machinery | one resolver/composer and existing upgrade tool | no new resolver, service, registry, ledger, poller or consumer fast path |
