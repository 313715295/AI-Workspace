# Framework 1.6.0

- lifecycle: `DRAFT / NOT_CONSUMABLE / NOT_CURRENT / NOT_PIN_ELIGIBLE`
- baseline: immutable Framework 1.5.2
- release class: `MINOR`

This candidate keeps the 1.5.2 task-card schema and default load behavior. It adds only the minimum project-control contracts needed for routine Git exclusions, current-controller epoch binding, lighter routing/resource rules, unified-language governance, and a default-off project knowledge contract with schema, checker, and an explicit optional loader selector.

It deliberately does not ship remote transaction DTOs, retry/compensation ledgers, resource-binding files, controller-route messages, legacy authorization inventories, peer-reuse checkers, knowledge content, common knowledge aggregation, Pocket Legion knowledge initialization, or project slimming. Those are removed, deferred, or handled as direct task/host contracts.

Integration of the default-off knowledge infrastructure is complete, but the candidate is not a release. Passing direct tests does not authorize creating `framework/versions/1.6.0`, replacing live root scripts, changing `framework/CURRENT`, adopting it in a project, or initializing Pocket Legion knowledge.
